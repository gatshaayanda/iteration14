# iB — Iteration 14 / Backpack

**Business and everyday life. Connected.**

iB is Admin Hub's connected operating system for the two environments people move between: business and everyday life.

- **Briefcase / B.OS:** Iteration 13, the Business Operating System.
- **Backpack:** Iteration 14, the Personal Operating System.
- **iB:** the unified product identity and connected experience.

The Briefcase and Backpack remain independently useful spaces. A person owns one identity and can move between them. Data, publishing and invitations remain permissioned; connecting spaces never means automatically exposing private information.

## Product positioning

**A Briefcase for business. A Backpack for life. One connected system.**

The Backpack contains two modes:

- **Publish / My Channel:** custom viewing page, episodes, videos, announcements, private audiences, comments/contributions and an organised media library.
- **Organise / My Life:** personal lists, plans, notes, records, projects, goals, private documents and selected sharing.

The owner can use both modes together.

## Repository role

This repository is the Iteration 14 implementation of the Backpack environment and a connected component of iB. Iteration 13 remains the Briefcase/B.OS implementation and the shared engineering standards reference. Do not turn either repository into a disposable copy of the other.

## Current status

This is the initial product and architecture foundation. No claim is made that shared identity, cross-device persistence, publishing permissions, audience access or cross-app linking are already implemented. See [AGENTS.md](./AGENTS.md) for the verified repository baseline and next action.
